# Anya Messenger

Мессенджер с нуля на Python + FastAPI. Регистрация, личные чаты, группы, каналы, чёрный список, тёмная тема, кастомные фоны. Мгновенная доставка через WebSocket.

## Возможности

- **Регистрация и вход** — сессии через подписанные куки
- **Личные чаты** — один-на-один, мгновенная доставка через WebSocket
- **Группы** — создание, добавление участников, кик, роли (владелец / админ / участник)
- **Каналы** — пишут только админы, остальные читают
- **Чёрный список** — взаимная блокировка в личках
- **Superadmin** — защищённые аккаунты, которых нельзя заблокировать
- **Аватарки** — загрузка изображений с ограничением по размеру и типу
- **Фоны чата** — 10 градиентов + загрузка своих картинок
- **Тёмная / светлая тема** — с сохранением в localStorage
- **Адаптив** — десктоп, планшет, телефон
- **История сообщений** — всё хранится в базе

## Стек

- **Backend:** Python 3.11+, FastAPI, SQLAlchemy, SQLite
- **Реальное время:** WebSocket
- **Frontend:** Jinja2, HTML, CSS, Vanilla JS
- **Аутентификация:** passlib[bcrypt], itsdangerous
- **Формы / файлы:** python-multipart

## Требования

- Python 3.11 или выше
- pip
- Интернет (для установки зависимостей)

## Установка

```bash
# 1. Клонировать репозиторий
git clone https://github.com/klimakorykin-sudo/anya-messenger.git
cd anya-messenger

# 2. Установить зависимости
pip install -r requirements.txt

# 3. Создать папки для загрузок (если их нет)
mkdir -p static/avatars static/backgrounds

# 4. Запустить сервер
uvicorn app:app --reload
```

После запуска открой в браузере:

```
http://127.0.0.1:8000
```

## Первый запуск

1. Открой `http://127.0.0.1:8000/register`
2. Зарегистрируйся: имя, email, пароль (от 6 символов)
3. Войди
4. Найди другого пользователя во вкладке «Люди» — начни чат

## Как проверить работу в двух окнах

Чтобы протестировать чат с двух аккаунтов одновременно:

1. Обычное окно браузера — залогинься как **первый** пользователь
2. **Инкогнито** (Ctrl+Shift+N) — залогинься как **второй**
3. Оба зайди в один и тот же чат — сообщения летают мгновенно

> Инкогнито — это **отдельное хранилище куки**. В обычных двух вкладках ты будешь одним и тем же человеком, тест не сработает.

## Как это работает (кратко)

- **Сессии** — подписанный токен в куке (`itsdangerous`). Пароли — `bcrypt`.
- **WebSocket** — при входе в чат клиент открывает соединение `/ws/chat/{chat_id}`. Сервер рассылает сообщения всем участникам комнаты.
- **База** — SQLite. Модель: `Chat` + `ChatMember` (многие-ко-многим с ролями) + `Message` + `Blacklist`.
- **Superadmin** — флаг `is_superadmin` на `User`. Таких нельзя заблокировать.

## Ограничения

- SQLite — для локальной разработки. Для продакшена — PostgreSQL.
- Файлы (аватарки, фоны) хранятся локально в `static/`. Для продакшена — S3 или аналог.
- Секретный ключ для сессий — хардкод в `auth.py`. Для продакшена — переменная окружения.
